# Mesa V1 patch workspace

Place reviewed `.patch` or `.diff` files for the Mesa 24.3.0 baseline in this directory.

Recommended naming:

```text
0001-rp5-a650-description.patch
0002-rp5-a650-description.patch
```

Each patch should state:
- Mesa base version/commit
- affected source files
- expected effect
- known risks
- test status

Do not commit generated build output here.
